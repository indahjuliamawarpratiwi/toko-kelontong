# Toko Kelontong
Web untuk membantu pengelolaan stok dan transaksi pada toko kelontong. Sistem menyediakan fitur CRUD barang, pencatatan penjualan, manajemen restok, monitoring stok menipis, serta laporan transaksi yang memudahkan pemilik toko dalam mengelola persediaan barang secara efisien.

# Fitur Utama
1. Manajemen data barang (Tambah, Edit, Hapus, Cari)
2. Pengelolaan stok barang
3. Transaksi penjualan dengan pengurangan stok otomatis
4. barang dengan penambahan stok otomatis
5. Dashboard statistik
6. Notifikasi stok menipis
7. Riwayat transaksi
8. Laporan penjualan

# Teknologi yang Digunakan
- PHP Native
- MySQL
- Bootstrap 5
- HTML, CSS, JavaScript
- XAMPP (Development Environment)

# Tujuan Proyek
Proyek ini dibuat untuk membantu digitalisasi pengelolaan toko kelontong sehingga proses pencatatan stok dan transaksi menjadi lebih cepat, akurat, dan terorganisir.
